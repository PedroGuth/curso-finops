# Contribuindo 🤝

Contribuições são bem-vindas! Se você encontrou um erro, tem uma sugestão ou quer adicionar conteúdo, siga os passos abaixo.

## Como Contribuir

1. Faça um fork do repositório
2. Crie uma branch para sua alteração (`git checkout -b minha-melhoria`)
3. Faça suas alterações
4. Commit com uma mensagem clara (`git commit -m "fix: corrige query de custo diário"`)
5. Push para sua branch (`git push origin minha-melhoria`)
6. Abra um Pull Request

## O que Aceito

- ✅ Correções de erros em scripts, queries ou policies
- ✅ Novos scripts de automação FinOps
- ✅ Novas queries Athena úteis para análise de custos
- ✅ Melhorias nos guias dos laboratórios
- ✅ Traduções e correções de português

## Padrões

- Scripts bash com `set -euo pipefail` e suporte a `--dry-run`
- Policies em JSON válido
- Queries SQL com comentário descritivo no topo
- Markdown com formatação consistente
