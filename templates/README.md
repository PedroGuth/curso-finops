# Templates de Relatórios FinOps 📝

Modelos prontos para documentar e comunicar a prática de FinOps na sua organização.

## Templates Disponíveis

| Template | Para quem | Frequência |
|----------|-----------|------------|
| `relatorio-mensal-custos.md` | Equipe técnica + gestão | Mensal |
| `relatorio-executivo-finops.md` | C-Level / Diretoria | Trimestral |
| `plano-otimizacao-custos.md` | Equipe FinOps + Engineering | Por projeto |

## Como Usar

1. Copie o template desejado
2. Preencha com os dados reais da sua conta AWS
3. Use o **Cost Explorer** e **CUR** para obter os números
4. Distribua para os stakeholders relevantes

## Dicas

- Comece pelo **relatório mensal** — é o mais prático e gera valor rápido
- O **relatório executivo** deve focar em números de negócio, não técnicos
- O **plano de otimização** é ideal para alinhar prioridades com a gestão
- Automatize a coleta de dados com as [queries Athena](../queries/) do repositório
